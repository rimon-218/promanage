ProManage - Business Management
Dashboard

ProManage is a modern, responsive,
and user-friendly Business Management
Dashboard built with HTML, CSS, and
Vanilla JavaScript. It helps users
manage customers, products, sales,
inventory, and business reports through
a clean and intuitive interface.

Features

- Dashboard Overview - View total
  revenue, orders, customers, and
  products.
- Customer Management - Add, edit,
  delete, search, and manage customers.
- Product Management - Manage
  products, categories, prices, stock, and
  product images.
- Sales Management - Record sales,
  calculate amounts automatically, and
  update inventory.
- Revenue Chart - Visualize monthly
  revenue trends.
- Inventory Overview - Monitor product
  stock levels.
- Low Stock Filter - Quickly identify
  products with low inventory.
- Search Functionality - Search
  customers, products, and sales records.
- Pagination - Navigate large data
  tables easily.
- CSV Export - Export customer,
  product, and sales records.
- Dark / Light Mode - Switch between
  themes.
- Responsive Design - Optimized for
  desktop, tablet, and mobile devices.
- LocalStorage - Save dashboard data in
  the browser.
- Product Image Upload - Upload
  product images directly from your
  device.
- Demo Data - Includes sample
  customers, products, and sales records.

Installation

1. Download and extract the project ZIP
   file.
2. Open the extracted project folder.
3. Double-click "index.html".
4. The dashboard will open in your web
   browser.

No additional installation, build tools, or
dependencies are required.

How to Use

1. Open the dashboard in your browser.
2. Navigate through Dashboard,
   Customers, Products, Sales, Reports,
   and Settings.
3. Add customers and products.
4. Create sales using available
   customers and products.
5. Monitor revenue and inventory
   statistics.
6. Export records as CSV files.
7. Switch between dark and light
   themes.

Data Storage

ProManage uses browser LocalStorage
to save customer, product, and sales
information.

Important: This is a frontend-only demo
project. It does not include a backend,
server-side database, user
authentication, or cloud
synchronization. Data is stored locally in
the browser.
